# IE3110R Bus 96 GeoJSON Project

This project contains Bus 96 route and bus stop GeoJSON data, plus a Python script for calculating stop-to-stop route chainage.

## Data credit

Route and bus stop data are credited to [BusRouter SG](https://busrouter.sg/).

## Files

- `bus_96_busrouter_sg.geojson` — Bus 96 route geometry
- `bus_96_stops.geojson` — Bus 96 bus stop locations
- `bus96_route_chainage.py` — calculates chainage along the route
